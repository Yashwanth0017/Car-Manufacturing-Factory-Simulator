# Car Manufacturing Factory Simulator

A C++ Object-Oriented Programming project that simulates a simplified car manufacturing process.

## Features

* Manage car parts inventory
* Create cars
* Simulate car assembly
* Simulate car painting
* Perform quality checks
* Track car production status

## OOP Concepts Used

* Classes and Objects
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction

## Production Process

Parts Inventory → Assembly → Painting → Quality Check → Finished Car
